# Fabric Shortcuts & Productivity Notes

Quick shortcuts and workflow tips used during Portfolio Project #1.

---

## 🧭 Workspace Navigation

- `Shift + Enter` — run notebook cell  
- `Ctrl + B` — toggle sidebar  
- `Ctrl + S` — save notebook  

---

## 📁 Lakehouse Explorer Tips

- Drag-and-drop CSVs into Bronze  
- Use “Preview” to validate schema  
- Use “Open in SQL” for quick queries  

---

## 🔧 Pipeline Debugging

- Check run history  
- Validate input/output row counts  
- Use “Retry” for failed activities
