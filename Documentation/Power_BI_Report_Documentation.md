# Power BI Report Documentation — Gold Analytics

This document describes the Power BI visuals built on top of the Gold Lakehouse tables.

---

## 🧩 Gold Sales Validation Report

- Validates Gold table accuracy  
- Shows category-level totals  
- Confirms pipeline correctness  

---

## 📈 Matrix View

- Row-level breakdown  
- Category + subcategory  
- Revenue and quantity validation  

---

## 📊 Category Breakdown

- Visual summary of category performance  
- Used for business insights  
- Connected directly to SQL endpoint  

---

## 🔗 SQL Endpoint Connection

Power BI connects using:
- Lakehouse SQL endpoint  
- DirectQuery or Import mode
